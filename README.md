# Isaac Synergy Planner (Beta)
Welcome to the [Isaac Synergy Planner!](https://kopmerr.github.io/Isaac-Synergy-Planner/) This is a simple, experimental tool built for The Binding of Isaac: Repentance+ fans.

### About this project
This project was born out of "vibe-coding" — a collaborative process where the code was generated by AI, guided by my vision. Please keep in mind that this is not a serious commercial software project. It is a passion project built by one person, and it is currently in its early Beta stage. You might find that basic synergies are still missing, but I am just getting started!

### Future Plans
I have big plans for this planner! I intend to improve it over time, both with my own ideas and with your feedback. My goal is to eventually include:

> Trinkets and character-specific interactions.

> Advanced synergy logic (e.g., specific interactions like Tainted Magdalene + Habit + Car Battery with her built-in Yum Heart).

> Better item database and UI improvements.
